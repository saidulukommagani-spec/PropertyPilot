## Cross-cutting architecture/configuration

- **Security:** JWT filter/service and Spring method security exist. `CustomUserDetailsService` emits only `ROLE_<code>` authorities. `SecurityService` checks ownership for properties/documents/leads/deals and those methods are used in corresponding services. Service request, evidence, payment and many other resource access paths do not use equivalent ownership checks. Controller routes mix `/api/v1/...` and `/api/...`; `SecurityConfig` has specific `/api/v1` matchers followed by broad authenticated fallback. `BillingController` uses `hasAuthority('ADMIN')`, which does not match emitted `ROLE_ADMIN`, so those method-guarded endpoints are denied to standard admin principals. Other controllers use `hasRole`.
- **Scheduling:** `SubscriptionReminderScheduler`, `SubscriptionExpiryScheduler`, `SubscriptionAutoRenewScheduler`; app enables scheduling. Reminder is log-only. Auto-renew has no payment dependency and local `LocalDate.now()`.
- **Configuration:** `application-prod.yml` exists and configures DB env vars and less verbose app logging, but inherits base literal JWT secret, `ddl-auto: update`, root SQL/bind DEBUG and other base settings unless overridden. Compose forces `dev`, with literal DB credentials. `application-dev.yml` repeats weak defaults.
- **Database:** Runtime uses Flyway at `propertypilot-backend/src/main/resources/db/migration`; Hibernate schema update is simultaneously enabled. `my-database-migration-project/migrations/V1`â€“`V8` and docs SQL are separate histories not wired to backend. The backend migration set includes operations/marketplace/monitoring and extended models.
- **Repository boundary:** Controllers -> service interfaces -> implementations -> Spring Data repositories -> JPA entities is the intended layering, but some service implementation duplicates lifecycle work, and `ServiceRequestWorkflowService` is an unmatched interface.
- **Deployment/observability:** Dockerfile builds a non-root Java image; Compose is development-only. Actuator exposes health/info. No checked-in production orchestrator, CI deployment workflow, backup/restore procedure, alerting or tracing config was identified in the reviewed roots.
