# PropertyPilot - Business Requirements Document

## Project Name
PropertyPilot

## Tagline
Your Property. On Autopilot.

## Objective
Provide end-to-end property management services through a mobile application and web admin portal.

## User Roles

### Customer
- Register/Login
- Add Properties
- Request Services
- Track Requests
- View Documents

### Agent
- Manage Assigned Properties
- Handle Site Visits
- Update Service Status

### Admin
- Manage Users
- Manage Properties
- Manage Services
- Generate Reports

## Services

- Property Management
- Site Visits
- Document Verification
- Construction Services
- Maintenance Services
- Agriculture Services
- Marketplace Services

## Platforms

- Android App
- iPhone App
- Web Admin Portal

## Authentication

- Mobile Number Login
- OTP Verification
- Role Based Access

## Future Features

- AI Property Assistant
- Property Valuation
- Lead Marketplace
- Subscription Plans
# Pricing Engine

The system shall support dynamic pricing based on:

- Service Charge
- Distance
- Food Allowance
- Add-On Services
- Platform Fee
- Admin Overhead
- Profit Margin

All pricing values shall be configurable through Admin Portal.
# Agent Payout Engine

The system shall support separate payout calculations for agents.

Customer pricing and agent payouts shall be independent.
# Service Start ETA

Distance Based ETA

0-20 KM = 2 Days

20-30 KM = 3 Days

30-70 KM = 5 Days

70-100 KM = 7 Days

More than 100 KM = 14 Days

Admin configurable.
# Location Driven Architecture

Every property shall have:

- Latitude
- Longitude

Every agent shall have:

- Home Cluster
- Current Location

The system shall support future geofencing and live tracking.
# AI Analysis

Every completed service may generate:

- Service Summary
- AI Analysis
- Risk Assessment
- Recommendations
