## Platform overview

PropertyPilot is built around property operations, service management, customer lifecycle management, reporting, and field operations automation.

## Core domains

- Customer management
- Property management
- Service requests and visits
- Evidence and reporting
- Admin operations
- Partner, vendor, and agent management

## Recommended workflow

1. Review business strategy and product scope
2. Validate architecture and standards
3. Review canonical data and API contracts
4. Build SQL schema and backend services
5. Implement Flutter mobile app and React admin portal
6. Validate through QA and runbooks
