# PropertyPilot Code Review Instructions

Review the complete PropertyPilot codebase.

Read:

- Entities
- Repositories
- Services
- Controllers
- DTOs
- Security
- Configurations
- Tests
- Migrations

Do not review only file names.

Inspect actual implementation.

Use the following documents as source of truth:

1. PROPERTYPILOT_BUSINESS_CONTEXT.md
2. PROPERTYPILOT_ENTERPRISE_AUDIT_CHECKLIST.md
3. PROPERTYPILOT_MASTER_ROADMAP.md

Evaluate:

- Business alignment
- Missing functionality
- Architecture quality
- Security
- Scalability
- Production readiness
- Technical debt
- Duplicate code
- Dead code
- Missing tests
- Missing APIs
- Missing business workflows

Produce:

1. Executive Summary
2. Domain Gap Analysis
3. Architecture Gap Analysis
4. Security Review
5. Production Readiness Score
6. Prioritized Action Plan

Classify the system as one of:

- Prototype
- MVP
- Business Ready
- Production Ready
- Enterprise Ready
- Scale Ready
