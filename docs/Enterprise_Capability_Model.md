# PropertyPilot Enterprise Capability Model

## Version

1.0

---

# Purpose

This document defines the enterprise business capabilities of PropertyPilot.

A capability represents:

"What the business must be able to do."

Capabilities are:

- Stable
- Technology agnostic
- Organization agnostic
- Process agnostic

# Capability Maturity Scale

```text
1 - Initial

2 - Developing

3 - Defined

4 - Managed

5 - Optimized
```

---

# Governance Rules

1. Every business capability shall have an owner.

2. Capabilities shall remain technology agnostic.

3. Capabilities shall align with domain boundaries.

4. New initiatives shall map to capabilities.

5. Applications shall support defined capabilities.
