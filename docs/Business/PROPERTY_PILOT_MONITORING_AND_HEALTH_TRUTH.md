# PROPERTY PILOT MONITORING AND PROPERTY HEALTH TRUTH

Version: 1.0
Status: AUTHORITATIVE BUSINESS DOCUMENT

## Purpose

PropertyPilot provides recurring monitoring, inspection,
property health assessment, recommendations,
and long-term property management services.

Monitoring and Property Health are core differentiators
of the PropertyPilot business model.


Monitoring can be:
- Subscription Based
- One-Time Service Request

Property Health can be:
- Subscription Based
- One-Time Service

Multiple Monitoring Services per Property:
- Allowed

Monitoring Frequency:
- Admin Configurable

Missed Visits:
- Auto Reschedule + Admin Notification

Pause Monitoring:
- Supported

Recommendations:
- Supported

Recommendation → Quote → Service Request
(required for chargeable work)
