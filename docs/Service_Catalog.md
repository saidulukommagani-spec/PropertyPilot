# Service Categories

## 1. Property Verification Services

### Ownership Verification
Description:
Verify ownership details of the property.

Applicable To:
- Open Plot
- House
- Flat
- Agriculture Land
- Commercial Property

### Encumbrance Certificate (EC) Verification

Description:
Verify EC records and identify registered transactions.

Applicable To:
- All Property Types

### Registration Verification

Description:
Validate registration documents and ownership records.

Applicable To:
- All Property Types

### Survey Number Verification

Description:
Verify survey number and associated records.

Applicable To:
- Open Plot
- Agriculture Land

### Layout Approval Verification

Description:
Verify HMDA, DTCP, RERA or local authority approvals.

Applicable To:
- Open Plot
- Layouts
