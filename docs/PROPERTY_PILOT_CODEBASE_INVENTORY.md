# PropertyPilot Codebase Inventory

## Business model reference

This inventory was prepared after reading `docs/Business/PROPERTY_PILOT_BUSINESS_TRUTH.md` as the authoritative business model. PropertyPilot is a property-centric, service-centric operating platform. Customers purchase services from PropertyPilot; agents, vendors and partners are fulfillment resources. A typical operational chain is **Customer → Property → Service Request → Visit (when configured) → Evidence → Completion**. Leads represent opportunities; deals track revenue opportunities and may link to multiple service requests. Pricing, subscriptions, geo rules, notifications and auditability support service delivery. Property Health Check is a service category. Monitoring is an ongoing service category. AI recommendations are a future framework.

## Repository shape

The active backend is `propertypilot-backend` (Spring Boot / Java / PostgreSQL / Flyway). Other repository roots include `propertypilot-frontend` (React/TypeScript-named tree), `mobile_app` (Flutter), `admin-portal`, `backend`, `database`, and `infrastructure`. The last three named app/ops roots mainly contain planning READMEs and empty/planned subdirectories. Complete source file catalogs appear after the module map.

Current code counts: 496 production Java files; 78 Java test files; 38 Spring web controllers; 102 persistence entity classes; 101 repository interfaces; 24 Flyway SQL files; 154 frontend source files; one Dart file under `mobile_app/lib`.
